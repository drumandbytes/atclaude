Claude Code, in your shell prompt

Ask questions inline, use Claude as a step in a pipeline, and keep an encrypted, searchable history of everything you asked. It runs on your existing Claude Code login, with no API key.

GitHubDocumentation

Install

brew install drumandbytes/tap/atclaude
# or
curl -fsSL https://atclaude.drumandbytes.dev/install.sh | sh

Then add the shell integration to your startup file (zsh shown; bash, fish, PowerShell and Nushell are supported):

eval "$(atclaude init zsh)"

Use it

@claude "where is auth handled in this repo?"

journalctl -u app | @claude "output a JSON array of distinct error messages" | jq -r '.[]'

git diff | @claude "write a one-line commit message" | pbcopy

@claude --search "what was the issue with the deployment logs last week?" --since 2w

What you get

  • Pipeline-friendly. stdin is data, the argument is the instruction. When input or output is piped you get raw text: no markdown, no code fences, errors on stderr, a real exit code.
  • Safe by default. Read-only unless you pass -a (file edits) or -y (everything).
  • Sessions. Context carries over per terminal, per directory with a .atclauderc file, or under a name you choose.
  • History you own. Every turn is stored in an encrypted local database with its repo, branch, session and mode. Search it in plain language, browse it with fzf, delete or compact it. Keep it all, or turn recording off per call, project or machine.
  • Configurable. Every setting works as a flag, an environment variable, a project file or a global file.
